# appamass – AI Workflow Engineering

**Software that executes work.**

We design, build and operate production-ready systems that don't just manage operational business workflows, they execute them. Each system combines deterministic business logic, AI agents and human-in-the-loop into one integrated piece of software.

**Workflow first. System second. Agent third. Technology last.**

- **Deterministic software** for fixed rules and unambiguous processes
- **AI agents** for unstructured information and context-dependent decisions, inside a harness of tools, checks and controlled data access
- **Humans** for judgment, approvals and exceptions

Not everything needs AI. We use it only where code is not enough, and a human reviews the uncertain cases.

### How we build

AI agents are software components: clear states, guardrails enforced in code, automated tests, evals and observability. Models stay swappable, systems build on open standards and containerized infrastructure.

### Stack
